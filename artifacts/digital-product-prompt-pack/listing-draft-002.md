# Freelancer Client-Ops Prompt Pack

Status: validation draft 002

## Who this is for
Freelancers and solo operators who lose margin in the handoff between discovery call, proposal, and scope control.

## What is included
1. Discovery Call Summary Prompt
2. Proposal Clarity and Boundary Prompt
3. Scope Creep Early-Warning Prompt
4. Client Onboarding Checklist Prompt
5. Weekly Client Update Prompt

## Outcome target
Reduce unpaid revision cycles and tighten the path from first call to signed scope.

## Validation question
If you could fix one failure point this week, which would you pick?
- Proposal wording that causes confusion
- Scope boundaries that get ignored
- Onboarding handoff gaps
- Weekly update churn
