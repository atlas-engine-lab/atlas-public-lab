# Freelancer Client-Ops Prompt Pack

Status: draft for validation

## Who this is for
Freelancers and solo operators who lose time between discovery call, proposal writing, and onboarding setup.

## What is included
1. Discovery Call Summary Prompt
2. Proposal Clarity Prompt
3. Client Onboarding Checklist Prompt
4. Scope Gap Detection Prompt
5. Weekly Client Update Prompt

## Outcome target
Reduce admin friction from first call to signed scope with clearer handoff notes and fewer back-and-forth edits.

## Validation question
Which step currently breaks most often for you?
- Discovery notes
- Proposal language
- Onboarding checklist
- Scope-change handling

## Notes
This is an experiment artifact, not a final product listing.
